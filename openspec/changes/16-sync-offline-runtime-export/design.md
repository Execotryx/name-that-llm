# Design: one authoritative sparse runtime recipe

## Decision

Keep `uv.lock` authoritative and retain the existing generated requirements file. Regenerate with a documented fixed command equivalent to `uv export --locked --no-dev --no-hashes --no-emit-project --format requirements-txt --output-file requirements-runtime.txt`. Do not hand-maintain a second set of pins. Compare normalized requirement entries rather than the autogenerated command comment; all dependency/version/marker differences must fail the drift check.

Add the exported recipe to the execution code inventory and reuse the existing release copying loop. Verify that the package-root calculation works in the bundle's `source/ntl` layout. The installed dependency profile remains authoritative for the actual execution environment; the export records how that environment is staged, not proof it was installed correctly.

## Verification boundary

Use a fresh unseeded environment with no system-site-packages and no project editable install that would resolve missing dependencies. Stage pinned wheels during the acquisition phase, install only the exported requirements from those wheels with network disabled, and import the source package through the same layout used by the notebook. Exercise CLI/help, `ntl.release`, runtime-profile capture and a tiny synthetic sparse fit/Parquet contract. Assert that torch/transformers are neither required nor imported. Do not require exact equality between installed distributions and the export: installation tools may exist, but they cannot supply undeclared application requirements.

A cheap export-drift check can run routinely; the isolated installation check belongs to packaging validation. Record Python, platform, wheel hashes, command, exit status and import/contract results. Installation or import failure blocks packaging readiness with an actionable missing-package message; execution must not download a repair.

## Migration and constraints

Changing execution identity invalidates affected G0/G1/downstream evidence. Register the amendment and regenerate affected evidence only under the existing unchanged split/search policy. Preserve historical runs, receipts and all reserved/exposed/closed G5 state. Do not reset a holdout to accommodate this packaging fix.

Full real target acceptance remains the existing change 02/07 responsibility. This change supplies a correct package and its local validation; it does not bypass the cold target gate.
